## Blinded annotation and independent review
Use only the official source and the blinded packet, not paired.json or detector overlays. Packet contains geometry, exact original span, hashes, blank reference and required keys. Two separate annotators independently submit 4 directional count keys and 64 queue labels for each holdout (68 per person per case). Count all finite line crossings during the span in either direction using signed side convention in analytics/geometry.py; note ambiguous cases outside the JSON, leave unresolved labels absent. Queue label is number stopped >=1 s in ROI at specified native frame; use image-foot convention. A zero is entered only after inspection; an absent key is unknown. Lower-FPS end-of-second samples are offset from the last native frame by <0.2s; note this limitation. No detector-generated labels, no guessed zero, no plates/faces, no real video publication. Keep working labels and annotator references private.
After two completed independent submissions, compare every key, resolve disagreements externally with a new submission from each annotator if appropriate; the software does not resolve disagreement. A third distinct reviewer explicitly accepts both exact canonical annotation hashes. Only then calculate direction-specific absolute error sum / truth total, undefined relative error if truth total zero, and queue MAE. Proposed research thresholds: <=5% count relative error (zero absolute error if zero truth), queue MAE <=1 vehicle. These are not municipal acceptance. Identity-level tracking and detection F1 require separately annotated bounding boxes and track identities; not generated by this aggregate protocol. No candidate promotion even if all aggregate thresholds pass: separate cross-camera validation, calibrated geometry and full v1 X/decision gates still needed.
