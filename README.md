# Semáforos Inteligentes

Plataforma de inteligência semafórica urbana, exclusivamente consultiva (advisory) e de simulação. Não atua em controladores nem em semáforos físicos.

O repositório é a fonte oficial do código, dos critérios de aceite e das evidências de validação. A fundação será entregue por pull requests, sem alegar homologação antes dos testes.
